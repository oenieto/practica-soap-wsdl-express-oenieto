# Práctica SOAP y WSDL con Express

Práctica de servicios web SOAP con Node.js y Express. La idea es tener dos servicios, cada uno con su WSDL:

- ConversionesService (`/soap/conversiones`)
- GeometriaService (`/soap/geometria`)

> En progreso, voy actualizando esto conforme avanzo.

## Instalación

```bash
npm install
```
